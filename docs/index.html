Send Guard

发送按钮前的隐私检查：在你把消息发出去之前，判断它是否透露了别人的隐私、能否让收件人认出具体的人。不阻止发送，只在值得再看一眼时提醒。

在线试玩 / Live demo 下载 / Download GitHub · 隐私政策 / Privacy Policy

它会做什么

  • 在 Gmail、Outlook、QQ 邮箱、Discord 按发送时检查，其他网站可手动检查；
  • 客套话和不涉及他人的短句在本地放行，不上传；
  • 自定义敏感词只在本地匹配；
  • 检查失败显示「检查未完成」，不会误报为安全。

它不会做什么

  • 没有自己的服务器，不收集任何数据；
  • 不读取收件人的名字、邮箱或用户名；
  • 不替你写或改消息。
